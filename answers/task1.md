# Task 1：从 C 源码到可执行文件

请用自己的语言简要说明下面几个阶段分别做了什么：

1. 预处理

 处理以#开头的指令，比如说#include，#define,#ifdef等，它将头文件内
容原本的插入源文件中并且展开所有的宏定义，并删除注释。预处理后，生成一个
扩展名为.i的文本文件，内容依旧为c语言的代码，但是没有预处理指令，就像
 #inlcude<stdio.h>替换为stdio.h中所有函数声明和类型定义，因此.i一般
比原来的.c文件大一些

2. 编译

 编译则将预处理后的.i文件翻译成为汇编语言文件，编译器对代码进行语法语义等
分析，检查变量类型函数声明等等是否正确，若错，则报错停止，编译结果面向CPU
架构的汇编代码。

3. 汇编

 将汇编代码转换为机器码，目标文件是二进制的格式，其中指令是CPU可以直接去执
行的二进制编码，但未分配最终的内存地址，对外部函数和全局变量的引用未处理

4. 链接

 将一个或多个目标文件以及所需的库文件合并，生成最终可执行文件，链接器将所
有目标文件中的符号引用解析，将各模块地址统一编排，并填入正确地址信息，完
成后，程序即可运行
